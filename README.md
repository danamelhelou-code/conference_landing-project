# DevSpace Conference — Landing Page

A landing page for a fictional tech conference called **DevSpace**, built with plain HTML and CSS (no JavaScript, no frameworks), including a separate registration page.

## Pages
- **index.html** — The main landing page, containing:
  - Header with logo and navigation (About, Speakers, Schedule, Pricing)
  - About section with a countdown display (days/hours/min/sec)
  - Speakers section
  - Schedule section (session timeline)
  - Pricing section (Basic / Standard / VIP tiers)
  - Footer
- **contact.html** — Registration/reservation page (form for name, email, phone, ticket type)
